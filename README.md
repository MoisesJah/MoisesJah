## Sobre mí

Desarrollador Full Stack independiente en Lima, Perú. Construyo sistemas web a medida, paneles administrativos, sitios corporativos, tiendas e-commerce y herramientas de automatización para PYMEs y empresas, cubriendo el ciclo completo: diseño, desarrollo, despliegue en VPS y mantenimiento.

- 🎓 Ingeniería en Sistemas (convalidando actualmente) — CENTRUM PUCP
- 💼 Freelance full stack — desde frontend/backend a infraestructura y SEO
- 📍 Lima, Perú — trabajo remoto para clientes locales e internacionales
